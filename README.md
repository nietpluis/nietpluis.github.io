# Niet Pluis! — Mysteries op Het Kompas

The website is a self-contained HTML page with its styles, scripts, and media
embedded in `index.html`. It has no build step or local asset dependencies.

## Preview locally

Open `index.html` in a browser, or serve the repository directory with any
local static-file server.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder, then save.
5. GitHub Pages will publish the site and show its URL in the Pages settings.

Edit `index.html` to change the website. Keep it at the repository root so
GitHub Pages uses it as the site’s entry page.
